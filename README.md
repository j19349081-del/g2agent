# G2Agent

1. **NotebookLM:** Use [NotebookLM Enterprise](https://cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs). The consumer product has no documented API for automated video generation/download; confirm Enterprise API coverage before relying on automation.
2. **YouTube API:** In [Google Cloud Console](https://console.cloud.google.com/), create a project, [enable YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com), configure [OAuth consent](https://console.cloud.google.com/auth/overview), and create a **Desktop app** client at [OAuth Clients](https://console.cloud.google.com/auth/clients). See [YouTube OAuth docs](https://developers.google.com/youtube/v3/guides/authentication).
3. **Authorize:** Run `./scripts/Connect-G2YouTube.ps1 -ClientIdFile "<path-to-client-json>"` and complete Google's consent flow. Keep the client JSON outside the repo; the scripts use local ADC credentials. See [Desktop OAuth guidance](https://developers.google.com/identity/protocols/oauth2/native-app).
4. **Configure and upload:** Run `./scripts/Get-G2Channel.ps1`, set the verified `expectedChannelId` in local `settings.json`, then create and review a job before uploading. Uploads default to private; public release requires approval. See [YouTube upload API](https://developers.google.com/youtube/v3/docs/videos/insert).
