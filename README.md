# G2Agent

## API setup

1. **NotebookLM:** For the consumer product, there is no documented public API or token flow to generate/download Video Overviews. NotebookLM Enterprise requires [product setup](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview) and the admin-assigned `roles/discoveryengine.notebookLmUser` role. However, Google's published docs do not document API endpoints for the complete create/add-source/generate/download workflow, so there is currently no supported NotebookLM API credential to create for this automation. Do not use API keys, session cookies, or private web endpoints as substitutes.
2. **Enable YouTube API:** In [Google Cloud Console](https://console.cloud.google.com/), create/select a project → [APIs & Services → Library](https://console.cloud.google.com/apis/library/youtube.googleapis.com) → **YouTube Data API v3** → **Enable**.
3. **Create OAuth credentials:** Open [Google Auth Platform](https://console.cloud.google.com/auth/overview), configure **Branding** and **Audience** (add your Google account as a test user if using Testing), then open **Clients → Create client → Desktop app** and download the JSON. In **Data Access**, add `https://www.googleapis.com/auth/youtube` (the scope used by these scripts). An API key is only for public data; it cannot upload videos.
4. **Authorize and use:** Run `./scripts/Connect-G2YouTube.ps1 -ClientIdFile "<full-path-to-downloaded-json>"` and approve access in Google's browser flow. This creates local ADC credentials; scripts obtain short-lived access tokens automatically. Keep the JSON outside the repo. Then run `./scripts/Get-G2Channel.ps1`, set the verified `expectedChannelId` in local `settings.json`, and use the job/upload scripts. Uploads default to private; public release requires approval. See [YouTube OAuth](https://developers.google.com/youtube/v3/guides/authentication), [Desktop OAuth](https://developers.google.com/identity/protocols/oauth2/native-app), and [video upload API](https://developers.google.com/youtube/v3/docs/videos/insert).
